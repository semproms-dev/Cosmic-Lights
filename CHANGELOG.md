# Change Log

## [1.1.0] - 2026-11-09

### Added

- Folder browsing with previews of compatible images contained within them.
- Enlarged view of the selected image, EXIF data summary, and file size.
- Centered notification when the folder does not contain compatible images directly at the top level. It closes automatically after four seconds and features a fade-out animation.
- Translations of the preview into Catalan, German, English, Spanish, Basque, and French.
